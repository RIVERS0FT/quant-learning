# 第九周 · 第五天

## Calmar 与超额收益：从绝对绩效走向相对绩效

---

## 1. 今日新名词

- **Calmar 比率**：年化收益与最大回撤幅度之比，衡量策略每承受一单位历史回撤获得了多少年化收益。
- **基准**：评价策略相对表现时使用的参照组合，例如沪深 300、中证 500 或与策略风格相近的指数。
- **主动收益**：策略单期收益减去基准单期收益。
- **相对净值**：策略财富相对于基准财富的比值。
- **跟踪误差**：主动收益波动率的年化值，衡量策略偏离基准的稳定程度。
- **信息比率**：年化主动收益除以年化跟踪误差。
- **相对回撤**：相对净值从历史高点向下回落的幅度。

# 一、Calmar 比率

## 3. 定义

本课程统一使用：

\[
Calmar
=
\frac{R_{\text{ann}}}{|MDD|}
\]

其中：

- \(R_{\text{ann}}\) 是几何年化收益。
- \(MDD\le 0\) 是带符号最大回撤。
- \(|MDD|=-MDD\ge 0\) 是最大回撤幅度。

分母必须使用最大回撤的绝对值。若直接使用负的 \(MDD\)，一个正收益策略反而会得到负的 Calmar，比率将失去直观意义。

## 4. 逐步计算

给定三期收益：

\[
10\%,\quad -20\%,\quad 25\%
\]

设期初净值为：

\[
V_0=1
\]

第一期净值为：

\[
V_1=1\times(1+10\%)
\]

\[
V_1=1.10
\]

第二期净值为：

\[
V_2=1.10\times(1-20\%)
\]

\[
V_2=0.88
\]

第三期净值为：

\[
V_3=0.88\times(1+25\%)
\]

\[
V_3=1.10
\]

峰值 \(1.10\) 到谷底 \(0.88\) 的回撤为：

\[
MDD
=
\frac{0.88}{1.10}-1
\]

\[
MDD=-20\%
\]

若这三个周期正好构成一年，则总增长因子为：

\[
G=1.10
\]

年化收益为：

\[
R_{\text{ann}}
=
G^{3/3}-1
\]

\[
R_{\text{ann}}=10\%
\]

因此：

\[
Calmar
=
\frac{10\%}{20\%}
\]

\[
Calmar=0.5
\]

它表示：该策略每承担一单位最大回撤幅度，获得了 \(0.5\) 单位的年化收益。

## 5. 为什么必须保留期初净值

假设收益为：

\[
-20\%,\quad 25\%
\]

正确财富路径是：

\[
1.00\rightarrow0.80\rightarrow1.00
\]

第一期回撤为：

\[
\frac{0.80}{1.00}-1=-20\%
\]

若只保存两个期末净值 \(0.80\) 和 \(1.00\)，程序或手工计算会把 \(0.80\) 错当成起点，从而漏掉第一期的亏损。

## 6. Calmar 的边界与局限

- 当净值从未下降时，\(MDD=0\)，Calmar 的分母为零，此时应记为未定义，而不是无穷大。
- 当年化收益为负且存在回撤时，Calmar 为负。
- Calmar 只使用最严重的一次回撤，不能反映其他多次小回撤。
- Calmar 对样本起止日期非常敏感，比较策略时必须使用相同区间。
- 短样本的年化收益可能被明显放大，因此不能只看 Calmar 一个指标。

# 二、基准与主动收益

## 7. 单期主动收益

策略第 \(t\) 期收益为 \(r_{p,t}\)，基准收益为 \(r_{b,t}\)，主动收益定义为：

\[
a_t=r_{p,t}-r_{b,t}
\]

若策略上涨 \(1.2\%\)，基准上涨 \(0.8\%\)，则：

\[
a_t=1.2\%-0.8\%
\]

\[
a_t=0.4\%
\]

这里的 \(0.4\%\) 是百分点差，表示策略当期比基准多赚了 \(0.4\) 个百分点。

## 8. 累计收益差

策略累计增长因子为：

\[
G_{p,T}
=
\prod_{t=1}^{T}(1+r_{p,t})
\]

基准累计增长因子为：

\[
G_{b,T}
=
\prod_{t=1}^{T}(1+r_{b,t})
\]

策略累计收益为：

\[
R_{p,\text{cum}}=G_{p,T}-1
\]

基准累计收益为：

\[
R_{b,\text{cum}}=G_{b,T}-1
\]

累计收益差为：

\[
\Delta R_{\text{cum}}
=
R_{p,\text{cum}}-R_{b,\text{cum}}
\]

它回答：在同一期间内，策略累计收益比基准高出多少个百分点。

## 9. 相对净值收益

相对净值为：

\[
W_{\text{rel},T}
=
\frac{G_{p,T}}{G_{b,T}}
\]

相对净值收益为：

\[
R_{\text{rel},T}
=
W_{\text{rel},T}-1
\]

代入累计收益后：

\[
R_{\text{rel},T}
=
\frac{1+R_{p,\text{cum}}}{1+R_{b,\text{cum}}}-1
\]

它回答：相同初始资金分别投资策略和基准后，策略最终财富相对基准高出多少比例。

## 10. 累计收益差为什么不等于相对净值收益

由相对净值定义：

\[
1+R_{\text{rel},T}
=
\frac{1+R_{p,\text{cum}}}{1+R_{b,\text{cum}}}
\]

两边乘以 \(1+R_{b,\text{cum}}\)：

\[
1+R_{p,\text{cum}}
=
(1+R_{b,\text{cum}})(1+R_{\text{rel},T})
\]

展开右侧：

\[
1+R_{p,\text{cum}}
=
1+R_{b,\text{cum}}+R_{\text{rel},T}
+R_{b,\text{cum}}R_{\text{rel},T}
\]

两边减去 \(1\)：

\[
R_{p,\text{cum}}
=
R_{b,\text{cum}}+R_{\text{rel},T}
+R_{b,\text{cum}}R_{\text{rel},T}
\]

再减去 \(R_{b,\text{cum}}\)：

\[
R_{p,\text{cum}}-R_{b,\text{cum}}
=
R_{\text{rel},T}
+R_{b,\text{cum}}R_{\text{rel},T}
\]

提取公因子：

\[
R_{p,\text{cum}}-R_{b,\text{cum}}
=
R_{\text{rel},T}(1+R_{b,\text{cum}})
\]

因此通常有：

\[
\Delta R_{\text{cum}}
\ne
R_{\text{rel},T}
\]

只有当基准累计收益接近零时，两者才可能近似相等。

## 11. 为什么不能直接连乘主动收益

精确的单期相对增长率为：

\[
q_t
=
\frac{1+r_{p,t}}{1+r_{b,t}}-1
\]

通分后：

\[
q_t
=
\frac{1+r_{p,t}-(1+r_{b,t})}{1+r_{b,t}}
\]

整理分子：

\[
q_t
=
\frac{r_{p,t}-r_{b,t}}{1+r_{b,t}}
\]

由于：

\[
a_t=r_{p,t}-r_{b,t}
\]

所以：

\[
q_t
=
\frac{a_t}{1+r_{b,t}}
\]

一般情况下：

\[
q_t\ne a_t
\]

因此，不能使用 \(\prod(1+a_t)-1\) 计算精确相对净值收益。正确方法是逐期连乘：

\[
\prod_{t=1}^{T}
\frac{1+r_{p,t}}{1+r_{b,t}}-1
\]

# 三、跟踪表现

## 12. 跟踪误差

主动收益均值为：

\[
\bar a
=
\frac{1}{N}\sum_{t=1}^{N}a_t
\]

主动收益的样本标准差为：

\[
s_a
=
\sqrt{
\frac{
\sum_{t=1}^{N}(a_t-\bar a)^2
}{N-1}
}
\]

若一年包含 \(A\) 个周期，年化跟踪误差为：

\[
TE_{\text{ann}}
=
s_a\sqrt A
\]

跟踪误差只描述相对基准偏离得有多不稳定，不判断这种偏离是否创造了收益。

## 13. 信息比率

主动收益的算术年化近似为：

\[
\mu_{a,\text{ann}}=A\bar a
\]

信息比率定义为：

\[
IR
=
\frac{\mu_{a,\text{ann}}}{TE_{\text{ann}}}
\]

代入两项：

\[
IR
=
\frac{A\bar a}{s_a\sqrt A}
\]

因为：

\[
A=\sqrt A\sqrt A
\]

所以：

\[
IR
=
\frac{\sqrt A\sqrt A\bar a}{s_a\sqrt A}
\]

约去分子和分母中的 \(\sqrt A\)：

\[
IR
=
\frac{\bar a}{s_a}\sqrt A
\]

解释：

- \(IR>0\)：策略平均跑赢基准。
- \(IR<0\)：策略平均跑输基准。
- \(|IR|\) 越大，主动收益相对于主动波动越稳定。
- 当跟踪误差为零时，信息比率没有稳定的有限定义。

## 14. 相对回撤

先构造相对净值：

\[
W_{\text{rel},t}
=
\prod_{i=1}^{t}
\frac{1+r_{p,i}}{1+r_{b,i}}
\]

相对净值历史高点为：

\[
H_{\text{rel},t}
=
\max_{0\le s\le t}W_{\text{rel},s}
\]

相对回撤为：

\[
D_{\text{rel},t}
=
\frac{W_{\text{rel},t}}{H_{\text{rel},t}}-1
\]

相对最大回撤为：

\[
MDD_{\text{rel}}
=
\min_t D_{\text{rel},t}
\]

相对最大回撤不是“策略最大回撤减去基准最大回撤”，因为两者的高点、低点和发生时间通常不同。

# 五、比较策略与基准的数据口径

比较前必须确认：

1. 策略与基准按相同日期对齐。
2. 两者使用相同收益频率，例如都使用日收益或都使用月收益。
3. 两者使用一致的复权口径。
4. 两者使用一致的币种和时区。
5. 策略和基准的费用口径明确。
6. 缺失数据不能在原因不明时直接填为零。
7. 价格指数与全收益指数不能随意混用。
8. 结果中应记录样本起止日期和有效观测数量。
